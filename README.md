# AI-powered workflow automation

A static landing page for an AI workflow automation product built with HTML, CSS, and JavaScript.

## What this project looks like

- A modern SaaS-style landing page
- Sticky header navigation
- Feature and use-case sections
- Smooth scroll interactions and element animations
- A newsletter contact section

## Project structure

- `index.html` — main page
- `assets/css/style.css` — styling
- `assets/js/main.js` — page interactions
- `assets/images/` — visuals and icons
